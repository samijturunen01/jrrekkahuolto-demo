Authorisation: the project owner (Hades Design) has confirmed permission to use and publish JR Rekkahuolto Oy's original logo, branding materials and authorised company photographs for this demo, including publication on GitHub Pages.

Original downloads are kept in `source-assets/`; every published variant is generated by `npm run images` (`scripts/process-images.mjs`).
